Privacidad

Informacion general sobre los datos utilizados para prestar el servicio Sehcontrol.

Datos de la cuenta

Sehcontrol almacena los datos necesarios para identificar la cuenta, administrar la membresia y asociar los equipos autorizados, como nombre, correo electronico y estado del plan.

Datos tecnicos

El servicio puede registrar identificadores de equipo, direccion IP, nombre del dispositivo, sistema operativo, version del cliente y fechas de conexion para operar y proteger la plataforma.

Uso de la informacion

La informacion se utiliza para autenticar usuarios, prestar el servicio de acceso remoto, administrar limites y vencimientos, enviar avisos y atender solicitudes de soporte.

Conservacion y seguridad

Los datos se conservan mientras sean necesarios para prestar el servicio y cumplir las obligaciones aplicables. Se aplican controles de acceso para limitar su consulta y modificacion.

Solicitudes

Para consultar, corregir o solicitar la eliminacion de datos personales, comunicate con el administrador o proveedor que te dio acceso a Sehcontrol.
